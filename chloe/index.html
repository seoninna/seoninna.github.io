① 전략·타겟제품·타겟·예산, KPI 설정
② 발굴·소재트렌드 인사이트, 광고 문구
③ 협의·제작인플루언서 추천, DM, 계약 초안

⑤ 성과·개선CTR·CVR·CPA·ROAS, 예산 조정

⚙ 백엔드: 프론트 → n8n Webhook → Code(데이터 정리) → AI Agent → Code(결과 검증) → 응답. 숫자 계산과 검증은 코드가, 글쓰기와 판단 보조는 AI가 맡아요.

n8n 연결 설정

Railway에 올린 n8n 주소를 넣으면 실제 AI 에이전트가 동작해요. 비워두면 데모 모드(미리 만든 예시 결과)로 동작합니다.

호출되는 Webhook 주소

막혔을 때
· 404: 워크플로가 Publish(Active) 안 됨, 또는 테스트 URL인데 'Execute workflow'를 안 누름
· 500: OpenAI Credential 미설정 또는 API 크레딧 부족
· Failed to fetch: 주소 오타, Railway 서비스 중지, 또는 CORS(Webhook 노드 → Options → Allowed Origins = *)
