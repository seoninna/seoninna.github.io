# 데이터 처리 경계 · 권한 · 네트워크 안내

> 이 문서나 프로그램 설정이 **보안을 보장하지 않습니다.** 실제 회사 원화 사용 가능 여부와 범위는 회사(정보보안·법무·팀장)의 승인으로 결정됩니다. "발표용"이라는 이유만으로 외부 전송 허가가 생기지 않습니다.

## 1. 무엇이 어디로 가는가

| 구성요소 | 실제 원화·추출문·렌더 이미지 | 외부 통신 |
|---|---|---|
| `local_preflight.py`, `pair_resolver.py`, `compare_engine.py` | 로컬에서 읽기 전용으로 열고, 결과는 `output_dir`에만 저장 | 프로그램 내부에서 비루프백 접속 차단(아래 3절) |
| `local_api.py` | 같은 PC의 n8n에게 **안전 요약**(pair_id·건수·상태 코드)만 반환 | 127.0.0.1에서만 대기. 공개 터널을 만들지 않음 |
| n8n (내 PC) | 원화 파일을 직접 읽지 않음. 실행 기록에는 안전 요약만 남음 | n8n 자체의 텔레메트리·버전 확인은 환경변수로 끄기(아래 4절) |
| 안전 요약 메일 (선택, 기본 OFF) | 문구·파일명·경로 없음. pair_id·건수·상태 | **외부 전송** — 승인 후에만 |
| APPROVED_EXTERNAL_B (선택, 기본 OFF) | **허가 자료/비기밀 재제작 자료만** Gmail·Drive·비교 서비스로 이동 | 외부 전송 |
| Claude Code / Claude 채팅 | **넣지 않음** | Claude Code는 외부 모델을 호출하는 도구입니다 |

## 2. Claude(AI) 사용 시 지킬 것
- 프로그램 코드는 Claude가 만들었지만, **실제 원화 처리는 Claude Code가 아닌 별도 터미널**에서 실행합니다.
- 원화 폴더·`output_dir`·`config.local.json` 을 Claude Code 프로젝트 폴더로 열거나 Claude에게 읽히지 마세요.
- 문제 공유는 화면의 **오류 코드와 건수만**. 보고서·스크린샷·파일명·경로·바코드·제품명을 붙여넣지 마세요.
- 프로그램은 오류 문구·스택트레이스를 출력하지 않도록 만들었습니다(파일 경로·문구 노출 방지). 그래도 화면을 공유하기 전 한 번 확인하세요.

## 3. 프로그램 내부 네트워크 차단의 한계
- LOCAL_ONLY 프로그램은 시작할 때 파이썬 소켓 연결을 감싸서 **127.0.0.1 이외의 접속을 거부**하고, 프록시 환경변수를 제거합니다(테스트로 확인).
- 이것은 **프로그램 안의 안전장치**일 뿐 운영체제 방화벽이 아닙니다. 다른 라이브러리·다른 프로그램(동기화 클라이언트, 백신, n8n 등)의 통신은 막지 못합니다.
- 실제 원화 처리 때 권장:
  1. 패키지 설치(`pip install`, `npx n8n` 최초 실행)는 **먼저** 끝낸다.
  2. 실제 비교는 회사 승인 PC에서 **네트워크를 끊은 상태**로 하거나, 회사 IT에 `python`(가상환경의 python 실행파일)의 **아웃바운드 차단 규칙**을 요청한다.
     - Windows: Windows Defender 방화벽 → 고급 설정 → 아웃바운드 규칙 → 프로그램 → `.venv\Scripts\python.exe` 차단 (관리자 권한 필요할 수 있음)
     - Mac: 회사 보안 솔루션 또는 방화벽 앱으로 해당 python의 외부 연결 차단 (기본 macOS 방화벽은 들어오는 연결만 제어)
  3. 차단 상태에서도 `local_api.py` ↔ n8n 은 127.0.0.1 내부 통신이라 동작합니다.

## 4. n8n을 내 PC에서 실행할 때
- 텔레메트리/외부 조회 끄기: `N8N_DIAGNOSTICS_ENABLED=false`, `N8N_VERSION_NOTIFICATIONS_ENABLED=false`, `N8N_TEMPLATES_ENABLED=false` (START_HERE 7장 명령에 포함). 사용 중인 n8n 버전 문서에서 변수명을 재확인하세요.
- 위 변수를 꺼도 n8n 서버는 외부 접속을 시도할 수 있습니다(2026-11-04, n8n 2.46.5 샌드박스 실행에서 `api.n8n.io` 접속 시도 로그 확인). n8n이 받는 데이터는 안전 요약뿐이지만, 정책상 필요하면 OS·방화벽으로 n8n(node)의 외부 접속을 차단하세요. 차단해도 127.0.0.1의 local_api 연결은 동작합니다.
- n8n은 실행 기록을 PC의 n8n 데이터 폴더(기본 `~/.n8n`)에 저장합니다. 이 워크플로가 받는 데이터는 안전 요약뿐이지만, 다른 워크플로를 추가할 때 원문이 들어가지 않게 하세요.
- Docker로 실행하면 컨테이너 안의 `localhost`는 컨테이너 자신입니다. 호스트의 `local_api.py`에 접근하려면 `host.docker.internal` 사용 + `local_api.host` 를 호스트의 도커 브리지 주소로 열어야 하므로(`allow_non_loopback_bind: true`) 같은 네트워크의 다른 기기 접근 위험을 IT와 검토하세요. `0.0.0.0` 바인드는 프로그램이 거부합니다.
- n8n에 원화 폴더를 마운트할 필요는 없습니다. 꼭 마운트해야 한다면 읽기 전용(`-v 원화폴더:/data/artwork:ro`).

## 5. 파일·폴더 권한
- 프로그램은 원본을 열기만 하고 쓰기·이동·삭제·이름 변경을 하지 않습니다(테스트: 실행 전후 원본 해시·수정시각 동일).
- 추가 안전장치가 필요하면 IT에 요청해 **작업 계정에 원화 폴더 읽기 전용 권한**만 주는 방법이 가장 확실합니다. (원본 폴더 속성을 직접 바꾸는 것은 회사 정책을 따르세요.)
- `output_dir` 에는 원화 문구·크롭 이미지가 들어갑니다. 원화와 같은 보안 등급으로 취급하고, OneDrive·iCloud·Google Drive 같은 **동기화 폴더에 두지 마세요**(회사 승인 저장소 제외). 보관 기간이 지나면 직접 삭제합니다.
- Mac에서 `ROOT_DIR_NOT_FOUND_OR_NOT_DIRECTORY` 가 나오면 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더(또는 전체 디스크 접근)에서 터미널 앱 권한을 확인하세요.
